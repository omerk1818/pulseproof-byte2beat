# 90-second Coder demo script

## 0–12 seconds — Problem
“Most heart-risk AI demos always return a number. PulseProof checks the data, measures uncertainty, and can refuse to answer.”

## 12–28 seconds — Coder evidence
Show the Coder template, create/open the workspace, and show the PulseProof application launching from the Coder dashboard.

## 28–48 seconds — Valid profile
Enter a plausible profile. Show the ensemble probability, REPORT/ABSTAIN decision, threshold, and individual model predictions.

## 48–62 seconds — Input safety
Enter an invalid profile such as systolic pressure below diastolic pressure. Show that the validity gate blocks inference.

## 62–76 seconds — Selective prediction
Use a borderline profile and show the ABSTAIN state. Say: “Reliable AI should be allowed to say: I don’t know.”

## 76–90 seconds — Research result
Show the project-story image or transportability chart: internal AUC 0.7991 versus second-dataset AUC 0.5487, with domain-shift AUC 0.9881.
